# Mentor Frameworks

Use mentor lenses as mirrors, not as cosplay or moral decoration. Tie each lens to concrete behavior from the user's day.

## Default Three Mentors

### 王阳明：知行合一，事上磨练

Use for the gap between known values and actual behavior.

Ask:
- 今天哪件事体现了“知道并做到”？
- 哪里是“明知应做，却没有行动”？
- 这个落差暴露了什么认知盲区？
- 明天要在哪一件具体事情上磨练？

Output:
- 相合之处
- 偏离之处
- 一条明日修正

### 曾国藩：日课反省，向内剖析

Use for disciplined self-audit and small recurring faults.

Ask:
- 今日之过是什么？
- 这个过错来自贪安逸、畏难、虚荣、浮躁，还是精力失守？
- 哪个微小习惯导致防线崩溃？
- 明天需要立哪一条可执行戒律？

Output:
- 今日之过
- 见微知著
- 明日戒律

Tone rule:
- Be direct.
- Do not humiliate the user.
- Critique behavior and mechanisms, not identity.

### 马斯克：第一性原理，极限执行

Use for stripping a task down to fundamentals and cutting false complexity.

Ask:
- 这件事的第一性原理是什么？
- 今天把问题复杂化在哪里？
- 哪些动作只是焦虑包装，不是真进展？
- 如果只允许一个极限动作，明天做什么？

Output:
- 第一性原理
- 复杂化/逃避之处
- 最小极限动作

## Optional Lenses

### 费曼：把复杂问题讲清楚

Use when the user is stuck in vague understanding, research, learning, or explanation.

Ask:
- 如果要讲给一个聪明的高中生，怎么讲？
- 哪个概念其实没有懂？
- 哪一步无法用自己的话解释？

### 查理·芒格：反向思考，避免愚蠢

Use when the user faces decisions, repeated mistakes, or preventable losses.

Ask:
- 如果想让明天彻底失败，我会做什么？
- 本周最大的愚蠢风险是什么？
- 哪个选择只是为了缓解焦虑？

## Mentor Output Rule

Every mentor critique must end with one concrete behavioral adjustment. Do not leave the user with abstract wisdom only.
