# Interview Prompts

Use these prompts when the user's raw material is incomplete or when deeper reflection is requested. Ask only what is needed; produce a useful draft after at most five questions.

## First Triage

Ask these before deep analysis if the day is unclear:

1. 今天大概分成哪几个时间段？上午、下午、晚上分别发生了什么？
2. 哪件事最让你开心、松一口气，或觉得自己还在前进？
3. 哪件事最让你内耗、沮丧、逃避，或精神不振？
4. 今天身体状态如何？睡眠、训练、饮食、疲劳有什么关键点？
5. 如果明天只能修正一件事，你直觉上会选什么？

## 轻问

Use when the user is tired, low-energy, sad, or asks for gentleness.

- 这件事让你难受的部分，最像哪一种感觉：委屈、害怕、无力、羞耻、孤独，还是别的？
- 如果不急着评价自己，今天其实已经承受了什么？
- 今天有没有一个很小但真实的前进？
- 这个情绪想保护你免受什么伤害？
- 明天能不能只做一个不伤害自己的最小动作？

## 深挖

Use when the user wants pattern discovery and can tolerate sustained inquiry.

- 这个情绪第一次出现是在今天的哪个具体瞬间？
- 在这个瞬间之前，你心里默认了什么判断？
- 你真正害怕的后果是什么？
- 这个行为短期帮你逃开什么，长期又夺走什么？
- 如果把这件事当成一个系统问题，触发器、回路、奖励分别是什么？
- 今天的“事件之心”到底是事件本身，还是事件暴露出来的旧模式？

## 严厉拷问

Use only when the user chooses a harsh mode. Be unsparing about behavior, but never attack identity.

- 不找借口地说，今天你逃避的具体动作是什么？
- 你说自己没状态，但有没有先破坏状态的行为？
- 这件事里，你是在解决问题，还是在用分析包装拖延？
- 如果明天继续这样，最直接的代价是什么？
- 你需要砍掉哪一个看似合理、实际消耗你的习惯？

Forbidden moves in harsh mode:
- Do not say the user is worthless, weak as an identity, broken, hopeless, or doomed.
- Do not diagnose mental illness.
- Do not imply pain is morally deserved.

## Emotion Naming

Create a dual name after enough evidence is available:

```text
诗性命名：机制命名
```

Examples:

- 雾中铁门：启动阻抗与评价焦虑回路
- 空转的齿轮：虚假忙碌与逃避补偿
- 暗潮退场：低能量保护性撤退
- 玻璃战场：外界评价过载
- 未寄出的火：表达压抑与行动冻结

Naming rules:
- The poetic name should be concrete and image-based.
- The mechanism name should explain the behavioral or emotional loop.
- Avoid making the name sound like a clinical diagnosis.
- Reuse prior names if the same pattern recurs; this builds the user's emotional dictionary.
