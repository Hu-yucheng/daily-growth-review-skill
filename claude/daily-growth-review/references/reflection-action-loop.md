# Reflection-to-Action Loop

Use this gate whenever a previous review exists, the same difficulty returns, or reflection is not changing behavior.

## 1. Audit before interpretation

Read the prior primary outcome, definition of done, evidence, and progress.

| Status | Rule |
|---|---|
| `completed` | All required evidence exists. |
| `partial` | Pre-defined partial evidence exists, but completion was not reached. |
| `missed` | The user did not act or chose another priority. |
| `unknown` | Evidence is unavailable; never convert this to completed. |
| `blocked` | A verified external dependency prevented action. |

Do not shame an incomplete outcome. Classify the main cause as scope, capacity, opportunity, motivation, environment, unclear evidence, interruption, dependency, or changed priority.

## 2. Recurrence gate

Search the recent reviews for the same behavioral loop, even if its label changed.

- First comparable occurrence: explain the loop and run one small experiment.
- Second occurrence: compare the experiment with the new evidence and change one variable.
- Third occurrence: stop adding explanations. Require a structural action such as reducing scope, removing access, scheduling a checkpoint, changing the environment, adding accountability, or seeking appropriate support.

Record the recurrence count and the structural change selected.

## 3. Comparable growth

Use `scoring-and-growth.md`. Compare the current event with the last similar situation. If none exists, create a baseline and record `baseline_missing`.

## 4. Close with execution

Use `next-action-board.md` to create one primary outcome, 3–5 weighted subtasks, and at most two support tasks. The next plan must respond to the cause found during audit; do not merely rename yesterday's missed task.

## 5. Weekly evidence

Track:

- commitment closure rate;
- verified primary-outcome progress;
- repeated pain-point count;
- structural changes attempted;
- comparable improvements;
- delayed recall and transfer evidence.

Do not score growth from insight volume.
