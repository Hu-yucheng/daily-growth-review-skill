# Reflection Lenses and Optional Mentors

Use lenses as practical mirrors tied to the user's evidence. Public defaults are principle-based, not person-based.

## Default lenses

### Action alignment

- What did the user intend or commit to?
- What behavior and evidence actually appeared?
- What is the smallest correction that closes the gap?

### System improvement

- Is the bottleneck capability, opportunity, motivation, environment, dependency, or task design?
- Which one variable can be changed tomorrow?
- On a third recurrence, what structural change replaces more explanation?

### Sustainable energy

- Did sleep, body state, emotion, workload, or recovery affect execution?
- Which demand should be reduced, moved, or supported?
- What minimum version preserves continuity on a low-energy day?

### Learning transfer

- What can the user now explain or do without assistance?
- Where does recall become vague?
- What future situation should trigger transfer of the lesson?

## Optional user-chosen mentors

Use a named mentor, tradition, or framework only when the user's private profile selects it or the user requests it in the current conversation.

For each custom lens:

1. State the principle being applied.
2. Cite today's observable evidence.
3. Distinguish interpretation from fact.
4. End with one concrete adjustment.

Do not imitate a person's voice, invent what they would say, or turn a respected figure into moral decoration.
