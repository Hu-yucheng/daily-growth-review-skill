# Weekly Review Template

Use this when the user provides seven daily reviews, a week of rough notes, or asks for 周复盘.

## Required Inputs

Prefer seven daily reviews containing `周复盘索引字段`. If unavailable, accept rough weekly notes and ask for the missing anchors:

- most meaningful event this week
- repeated obstacle
- best energy period
- worst internal conflict
- body/training state
- long-term goal movement

## Synthesis Rules

- Do not rewrite seven daily diaries.
- Focus on repeated patterns, score movement, mentor deviations, and emotional mechanisms.
- Use direct quotes from daily reviews only when they are short and diagnostic.
- Prefer one main battle over many scattered goals.
