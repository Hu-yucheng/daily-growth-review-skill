# Daily Growth Review Core Method

This file records the platform-neutral method shared by the Codex, Claude, and DeepSeek versions.

## Core Promise

Turn rough daily material into a Markdown growth archive that helps the user see patterns, name emotions, compare behavior against mentor principles, and choose the next action.

## Stable Modules

1. Reconstruct a practical timeline.
2. Identify the `事件之心`.
3. Explore emotions and create dual names: `诗性命名：机制命名`.
4. Apply mentor mirrors: 王阳明, 曾国藩, 马斯克.
5. Score fixed dimensions and long-term goals.
6. Recommend tomorrow's action.
7. Emit weekly index fields.

## Non-Goals

- Not a medical or psychotherapy tool.
- Not a productivity guilt machine.
- Not a passive diary logger.
- Not a replacement for Notion, Word, calendar, or activity tracking integrations.

## Portability Notes

- Codex and Claude use `SKILL.md` folders.
- DeepSeek uses the same method as a system prompt or agent instruction pack.
- Keep template section names stable so daily outputs can be reused for weekly review.
