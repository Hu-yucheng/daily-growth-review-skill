# Daily Growth Review v2 Core Method

This is the platform-neutral contract shared by Codex, Claude, and DeepSeek distributions.

## Promise

Adapt reflection to a private user profile, verify action with evidence, compare only a similar situation, create one auditable primary outcome, and preserve important learning for delayed recall.

## Required sequence

1. Load or progressively build the private profile.
2. Audit the prior outcome as `completed`, `partial`, `missed`, `unknown`, or `blocked`.
3. Separate the user's mainline from confidence-ranked patches.
4. Identify the event heart and reflective emotional mechanism.
5. Apply generic action, system, energy, and learning lenses.
6. Compare with the last similar situation or record `baseline_missing`.
7. Score four to six adaptive dimensions from 0–4 evidence anchors and a `-2..+2` comparison delta.
8. Build one primary outcome with 3–5 weighted subtasks totaling 100 and at most two support tasks.
9. Test delayed recall before showing prior explanations.
10. Use a connector only when capability, permission, execution, and verification are present.

## Public and private boundary

The public package contains schemas and methods only. Real profiles, journals, knowledge cards, platform IDs, tokens, webhooks, and connector configuration remain private and outside version control.

## Non-goals

- Not a diagnostic, therapy, or shame system.
- Not a universal life score.
- Not a personal WeChat listener.
- Not proof that an inaccessible link was read.
- Not proof that a reminder or external write occurred without verified tool output.
